# Scientific-Calculator-App
A modern and user-friendly scientific calculator with advanced functions, smooth interactions, and responsive design.
A fully interactive scientific calculator built with HTML, CSS, and JavaScript, featuring standard and scientific modes, DEG/RAD/GRAD angle switching, memory functions, and a live calculation history — all powered by a custom-built expression parser instead of eval() for safety. Building the parser from scratch (handling operator precedence, nested functions, and parentheses) was the most interesting part of the project, and it deepened my understanding of how calculators and interpreters actually evaluate expressions under the hood. I also learned a lot about creating smooth, responsive UI interactions — ripple effects, press animations, and glassmorphism styling — using pure CSS and JavaScript with no external frameworks.
